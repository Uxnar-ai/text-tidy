# 文本整理 txt · 一堆行粘进去就整好

> 把一堆行粘进去：去重、排序、去空行，再变成逗号串 / JSON 数组 / Markdown 列表 / SQL IN (...)。全部在浏览器里算，文本不上传。

[English](README.en.md) | 中文

## 这是什么

从服务器上抄下一堆 IP、文件名、ID，想拿去当参数用，通常得靠 `sort -u`、`sed` 拼半天。这页把那段活做成开关：粘进去，勾几个框，右边就是要的东西。

没有后端逻辑，只有一个空壳页面。处理分四步，顺序固定：去首尾空格 → 去空行 → 去重 → 改大小写 → 排序。去重保留第一次出现，末尾那个换行不算一条（否则行数永远多一行）。

输出格式是单独一步：一行一条、逗号串、JSON 数组、Markdown 列表、SQL `IN (...)`、每行加引号。SQL 那条会顺手把单引号翻倍，粘进语句里不会崩。设了 5 个预设按钮，日常那几种组合一次点完，不用每次手调下拉框。

## 功能

- 去首尾空格 / 去空行 / 去重 可自由叠加
- 排序 A→Z、Z→A、按长度、随机打乱、保持原顺序
- 输出 一行一条 / 逗号串 / JSON 数组 / Markdown 列表 / SQL IN / 每行加引号
- 5 个一键预设，日常组合不用手调
- 实时统计：原几行、结果几行、去掉几行重复、多少字节
- 粘贴即算（150ms 防抖），没有提交按钮
- 深色/浅色自适应 + 手动切换，窄屏单列不溢出
